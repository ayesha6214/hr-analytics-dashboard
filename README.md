# HR Analytics Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing HR data to understand employee attrition, workforce demographics, salary distribution, and employee trends using Power BI.

## 🎯 Project Objectives

- Analyze overall employee attrition.
- Understand employee distribution by gender and age group.
- Explore salary distribution across different salary slabs.
- Identify attrition trends across departments.
- Present HR insights through interactive visualizations.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation

## 🧹 Data Cleaning & Transformation

- Checked and handled duplicate records.
- Reviewed data types and corrected inconsistencies.
- Cleaned and transformed data using Power Query.
- Prepared data for dashboard reporting.

## 📊 Dashboard Features

- Employee Attrition Analysis
- Gender Distribution
- Age Group Analysis
- Salary Slab Analysis
- Department-wise Insights
- Interactive Slicers and Filters
